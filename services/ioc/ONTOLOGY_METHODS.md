# Ontology and directed method catalogue

Generated by `python tools/generate_catalogue.py`. Do not edit the tables manually.

**21 implemented methods; 39 disabled research candidates.**

A method is `(source, input type, output type)`. IOC edges are undirected; retrieval methods are directional.
Figure 3 membership is strict. Baseline `no` denotes documented IPv6 additions beyond Table I.

Implementation, configuration and live verification are separate:

- Implemented: a provider adapter and parser exist.
- Configured: local credentials/dependencies are present; this does not prove source access.
- Live verified: a particular method was tested at a recorded time; this is not a current availability guarantee.
- Candidate: not implemented; its retrieval route is unconfirmed, even if the type pair fits the ontology.

Use `python -m ioc_hunter methods --implemented --availability` to inspect local configuration without network calls.

Historical live checks on 10 October 2026: RapidDNS domain-to-IPv4 and VirusTotal domain-to-IPv4 returned partial results; OTX domain-to-IPv4 returned a loading page. Other routes are not live-verified. See LOOKUP_FOUNDATION.md.
